# port

고전 게임을 다른 기종에서 실행할 수 있게 만드는 포트와 호환 패치를 모아 두는 저장소입니다.
제작: **NP (Noctil Patchworks)**

## 배포 원칙

- **원본 게임은 배포하지 않습니다.** 배포 파일에는 원본 게임, 그림·음원·대사·맵 같은 게임 데이터, 완성된 게임 실행 파일이 들어 있지 않습니다.
- 사용자가 직접 가진 원본을 고르면, 사용자 PC에서 데이터를 추출·변환해 실행 파일을 만듭니다.
- 빌드 결과물에는 원본에서 추출한 게임 데이터가 들어가므로 **다른 사람에게 나눠 주지 마세요.**
- 비공식·비영리 팬 프로젝트이며 원작의 개발사·판매사와 관계가 없습니다. 게임의 권리는 각 권리자에게 있습니다.

## 마스터 오브 소드 3 PSP 포트

피처폰 게임 『마스터오브소드3』를 PSP에서 실행할 수 있도록 독립 포팅했습니다. 이동·전투·장비·메뉴·저장·불러오기를 구현하고, 조작을 PSP 버튼에 맞췄습니다.

배포 파일은 **빌더 ZIP**입니다. 원본 게임 ZIP을 고르면 빌더가 PSP용 게임을 만들어 줍니다.

**[최신 릴리스 받기 →](https://github.com/ievy3/port/releases/tag/mos3-v0.9.0)**

### 지원 원본

| 항목 | 값 |
|---|---|
| 게임 | 마스터오브소드3 |
| 플랫폼 | KTF WIPI Clet판 |
| 원본 버전 | 01.00.01 |
| 화면 크기 | 240×320 |
| 입력 형식 | 원본 게임 ZIP |
| ZIP SHA-256 | `3b72d4676d5dcc988cf3c0bf35ee963af0df4a59583af8d9ba2da6aed755784d` |

빌더는 원본 ZIP의 SHA-256을 검사합니다. 같은 버전이라도 **다시 압축한 ZIP은 해시가 달라져 거부될 수 있으니** 원본 ZIP을 그대로 선택해 주세요.

### 원본과 달라진 점

- **점프**: 방향키 ↑ 점프에 □ 버튼 점프를 더했습니다. 좌우 이동과 점프를 함께 쓰기 편합니다.
- **소리**: 전투 음성이나 효과음이 나올 때 배경음이 끊기던 것을 고쳐, 함께 재생되도록 했습니다.

### 사용 방법

1. 빌더 ZIP을 새 폴더에 압축 해제합니다.
2. `Prepare-Builder.cmd`를 실행해 필요한 도구를 준비합니다.
3. 준비가 끝나면 `Start-Builder.cmd`를 실행합니다.
4. 보유한 원본 게임 ZIP과 새 출력 폴더를 선택합니다.
5. 사전 검사 → 빌드를 진행합니다.
6. 완성된 `psp-build/Install.zip`을 압축 해제하고, 나온 `PSP` 폴더를 메모리스틱 최상위에 복사합니다.
7. PSP의 **게임 → 메모리스틱 → MoS3 NoLog Test**를 실행합니다.

PPSSPP에서는 압축을 푼 `PSP/GAME/MoS3NoLogTest/EBOOT.PBP`를 열면 됩니다.

**필요 환경**
- Windows x64. Python은 빌더에 들어 있습니다.
- 처음 도구를 준비할 때 인터넷 연결과 약 1.2GB 다운로드가 필요합니다.
- 전체 빌드는 시험 PC에서 약 11분 걸렸습니다. 도구 다운로드 시간은 따로이며, PC 성능에 따라 달라집니다.

### 기본 조작

| 버튼 | 동작 |
|---|---|
| 방향키 | 이동 · 메뉴 선택 |
| ○ | 공격 · 확인 · 대화 진행 |
| □ 또는 ↑ | 점프 |
| △ | 장착한 반지 능력 사용 |
| × | 플레이 중 아래 입력 · 메뉴에서 뒤로·취소 |
| START | 메뉴 |
| SELECT (대화 중) | 스킵 — 일부 주요 이벤트 제외 |

### 포함 및 자동 준비 도구

| 도구 | 용도 | 준비 방식 |
|---|---|---|
| Python 3.12.10 · Tk · pip | 빌더 실행과 화면 구성 | 빌더에 포함 |
| Ghidra 12.1.4 | 원본 실행 코드 분석·복원 | 자동 다운로드 |
| Eclipse Temurin JDK 21 | Ghidra 실행 | 자동 다운로드 |
| PSPSDK · PSP GCC 도구 모음 | PSP 실행 파일 컴파일·패키징 | 자동 다운로드 |
| Rust · Cargo · 링커 | 음원 변환 도구 빌드 | 자동 다운로드 |
| Capstone · Unicorn | ARM 코드 분석·실행 | 자동 다운로드 |
| Pillow · pycparser | 이미지 변환·C 코드 처리 | 자동 다운로드 |
| smaf · smaf-player · rustysynth | 피처폰 음원 해석·합성 | 자동 다운로드 |
| GeneralUser GS 사운드폰트 | 배경음 합성 | 자동 다운로드 |

도구는 빌더가 지정한 버전을 쓰며, 내려받은 파일의 해시를 확인합니다. Windows용 PSP 도구 묶음은 [dmang-dev/pspdev-win](https://github.com/dmang-dev/pspdev-win)을 사용합니다.

### 확인 범위

- 원본 선택부터 PSP 설치 ZIP 생성까지 실제 전체 빌드를 검증했고, 생성된 실행 파일과 게임 데이터가 기존 검증본과 일치하는 것을 확인했습니다.
- PPSSPP에서 기본 실행을 확인했습니다.
- PSP-1000을 기준으로 구성했습니다. 실기에서의 저장·절전 복귀 등은 추가로 확인하고 있습니다. **기존 저장 파일은 백업한 뒤 사용해 주세요.**
